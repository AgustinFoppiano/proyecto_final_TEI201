# Evidencias de las pruebas

## Videos del desarrollo

Los siguientes videos fueron recortados y se encuentran sin audio.

1. [Primera prueba del portapilas](primera_prueba_portapilas_sin_audio.mp4): se muestra la revisión de las conexiones y la colocación de una pila. Durante esta prueba, el botón blanco era el único conectado al portapilas; el botón azul correspondía al prototipo. Se observó calentamiento del portapilas. La temperatura no se midió y la causa de la falla sigue pendiente de identificar.
2. [Revisión del portapilas](revision_portapilas_sin_audio.mp4): se muestran el módulo y sus conexiones durante la revisión.
3. [Prueba de pantalla y motores](prueba_pantalla_y_motores_sin_audio.mp4): se muestran la pantalla OLED y los motores durante una etapa de pruebas del montaje.

También se conserva el [video de funcionamiento compartido anteriormente](https://drive.google.com/file/d/1kgygymFtD1YWlV5p6cyE6izTAz5sUehA/view?usp=sharing).
