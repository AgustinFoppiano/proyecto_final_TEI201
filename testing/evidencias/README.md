# Evidencias de las pruebas

## Videos del desarrollo

Si GitHub no muestra una vista previa, selecciona **View raw** para descargar y reproducir el video.

1. [Primera prueba del portapilas](primera_prueba_portapilas_sin_audio.mp4) (sin audio): se muestra la revisión de las conexiones y la colocación de una pila. Durante esta prueba, el botón blanco era el único conectado al portapilas; el botón azul correspondía al prototipo. Se observó calentamiento del portapilas. La temperatura no se midió y la causa de la falla sigue pendiente de identificar.
2. [Revisión del portapilas](revision_portapilas_sin_audio.mp4) (sin audio): se muestran el módulo y sus conexiones durante la revisión.
3. [Prueba de funcionamiento final](funcionamiento_final_con_audio.mp4) (con sonido): se muestra el funcionamiento de la pantalla OLED, los motores y el sonido de la alarma.

También se conserva el [video de funcionamiento compartido anteriormente](https://drive.google.com/file/d/1kgygymFtD1YWlV5p6cyE6izTAz5sUehA/view?usp=sharing).
