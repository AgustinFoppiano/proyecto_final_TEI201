# Fotografías de referencia de los componentes

Estas **fotografías de productos reales** están vinculadas a las páginas de los comercios o distribuidores señalados bajo cada imagen. No son imágenes generadas por IA ni fotografías de las unidades compradas por el equipo.

Las imágenes se muestran mediante sus enlaces externos y **no se reproducen como archivos nuevos dentro del repositorio**. Los créditos y enlaces de origen se incluyen para identificar sus proveedores. Los derechos corresponden a sus titulares; los enlaces externos pueden caducar. Para evidencia de la construcción se deben usar fotografías propias en [`hardware/fotos/`](../fotos/).
