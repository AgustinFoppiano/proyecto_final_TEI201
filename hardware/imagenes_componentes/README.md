# Ilustraciones genéricas de componentes

Las 10 imágenes SVG en esta carpeta fueron elaboradas como **ilustraciones originales referenciales**, con asistencia de ChatGPT (OpenAI), a petición del equipo.

Su propósito es identificar visualmente categorías de componentes en [el catálogo técnico](../componentes.md). **No son fotografías de las piezas compradas** y pueden variar en dimensiones, detalles y geometría respecto a las unidades reales.

Las fotografías originales y evidencias del prototipo deben publicarse separadamente en [hardware/fotos/](../fotos/). No utilizar estas ilustraciones para justificar mediciones ni para afirmar una marca o SKU concreto.
